# Inspiration and components

## Sites they love

When they name a site, open it (or ask for screenshots if you can't browse) and write down what makes it work:

- **Hero:** how many words, how big, what's behind it, where the button sits
- **Navigation:** how many links, what stays sticky, what happens on mobile
- **Type:** serif or sans serif, heading size, space between lines
- **Spacing:** room between sections, how wide the text column is
- **Imagery:** real photos, product shots, illustration, or video
- **Motion:** what moves, how fast, and what triggers it
- **The ask:** how they lead people to the main action

Tell them what you're taking in one sentence per site, like: "From Apple: huge headlines, lots of empty space, and one idea per screen."

Take the pattern. Never copy their text, photos, logos, or code.

### Good places to start

| Site | What to learn from it |
|---|---|
| apple.com | Empty space, one idea per screen, big confident headlines, product photos |
| nike.com | Bold imagery, heavy type, strong calls to action |
| airbnb.com | Friendly photos, simple search, trust through reviews |
| stripe.com | Explaining a complicated product clearly, polished details |
| linear.app | Dark mode done well, crisp type, restrained motion |

A competitor or a business they admire in their own industry is often the most useful reference of all.

## Component libraries

Most of these are React and Tailwind, copy and paste. Pick one base library (usually shadcn/ui) and one for flair. Restyle everything to the palette and fonts in the brief before it ships, because library defaults are a tell.

| Library | Good for | Know this |
|---|---|---|
| Originkit, https://originkit.dev | 250+ free animated components for React, Next.js, Vite, and Framer | Browse for free. Grabbing the code needs a free account. |
| 21st.dev, https://21st.dev | A huge community library of animated components | A free account gets a few copies a day, and a paid plan gets you unlimited. Anyone can submit, so read the code first. |
| shadcn/ui, https://ui.shadcn.com | The base layer: buttons, forms, dialogs, and menus | Most of the others plug into it |
| Magic UI, https://magicui.design | 150+ free animated components | Check the default colors. Some ship with an orange to purple gradient. |
| Aceternity UI, https://ui.aceternity.com | Cinematic hero sections and landing page effects | Free, with a paid Pro tier |
| React Bits, https://reactbits.dev | Text animations and animated backgrounds | MIT plus Commons Clause. Fine in any site, but you can't resell the components themselves. |
| tweakcn, https://tweakcn.com | A visual theme editor for shadcn/ui | Paste in the palette, copy out the theme |
| Motion, https://motion.dev | The animation library most of these use | Animate transform and opacity only |
| Cult UI, https://www.cult-ui.com | More components in the shadcn style | |
| Skiper UI, https://skiper-ui.com | Animated components and effects | |
| Shadcnblocks, https://www.shadcnblocks.com | Ready made page sections | Free and paid |
| v0, https://v0.app | Layout ideas when you're stuck | Use it for ideas, then build from the brief |

Before you use any component, read the code, check the license, and swap its colors, radius, and fonts for the ones in the brief.
